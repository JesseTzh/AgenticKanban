# 使用与部署

## 本地运行

环境要求：Go `1.26.3`、Node.js `22.22.2`。npm 依赖以 `web/package-lock.json` 为准。

```bash
go mod download
cd web && npm ci && npm run build && cd ..
go run ./cmd/server
```

访问 `http://localhost:8080`。服务会从 `WEB_DIST_PATH` 托管前端构建产物，默认目录为 `web/dist`。数据库没有用户时，服务将创建 `admin` 账号，并在启动日志中输出一次初始密码。

## Docker Compose

```bash
docker compose pull
docker compose up -d
```

## Docker 镜像部署

Docker Hub 镜像为 `jessetzh/agentic-kanban`，支持 `linux/amd64` 和 `linux/arm64`。在部署服务器上执行：

```bash
mkdir -p agentic-kanban/data
cd agentic-kanban
docker pull jessetzh/agentic-kanban:latest
docker run -d \
  --name agentic-kanban \
  --restart unless-stopped \
  -p 8080:8080 \
  -e APP_ENV=prod \
  -e HTTP_ADDR=:8080 \
  -e SQLITE_PATH=/app/data/agentic-kanban.db \
  -e SESSION_SECRET='replace-with-a-long-random-secret' \
  -e SESSION_TTL=24h \
  -e AGENT_TOKEN_SECRET='replace-with-another-long-random-secret' \
  -e WEBHOOK_BASE_URL=http://localhost:8080 \
  -e LOG_LEVEL=info \
  -v "$PWD/data:/app/data" \
  jessetzh/agentic-kanban:latest
```

将 `SESSION_SECRET` 和 `AGENT_TOKEN_SECRET` 替换为随机长字符串；如果通过域名或反向代理访问，同时将 `WEBHOOK_BASE_URL` 改为外部可访问的地址。首次启动时，初始 `admin` 账号密码会输出在容器日志中：

```bash
docker logs agentic-kanban
```

服务启动后访问 `http://<服务器地址>:8080`。SQLite 数据库保存在宿主机的 `agentic-kanban/data` 目录中，删除容器不会丢失数据。升级镜像时重新拉取镜像并重建容器，保留原有的数据目录即可：

```bash
docker pull jessetzh/agentic-kanban:latest
docker stop agentic-kanban
docker rm agentic-kanban
# 使用上面的 docker run 命令重新创建容器
```

## Docker Hub

`.github/workflows/publish-docker.yml` 会在 `main` 分支或 `v*.*.*` 版本标签推送时构建并发布镜像，同时支持手动触发。使用前在 GitHub 仓库的 **Settings > Secrets and variables > Actions** 中添加：

- `DOCKERHUB_USERNAME`：填写 `jessetzh`
- `DOCKERHUB_TOKEN`：具有推送权限的 Docker Hub Access Token

镜像地址为 `docker.io/jessetzh/agentic-kanban`。推送 `main` 会更新 `latest`，推送例如 `v1.2.3` 的版本标签会生成对应版本镜像。

## GitHub Pages

推送至 `main` 会触发 `.github/workflows/deploy-pages.yml`，构建前端并部署至 GitHub Pages。首次启用时，在仓库 **Settings > Pages** 中将部署来源设为 **GitHub Actions**。

Pages 构建自动启用 demo 模式，根路径展示登录页。任意用户名和密码都可以进入内置演示数据；写操作既不会请求后端，也不会持久化。

## 本地演示数据

```bash
go run ./cmd/seed
```

该命令默认写入 `data/agentic-kanban.db`，可通过 `SQLITE_PATH` 指定 SQLite 文件。脚本会执行迁移并补充缺失的固定演示记录，不会清空或覆盖现有数据。

| `developer` | `developer123` | 开发者 |
